# 🌿 نظام متابعة الاقتصاد الأخضر

منصة ويب مبنية باستخدام Flask لمتابعة مؤشرات الأداء البيئي للمؤسسات بشكل عملي وسريع، مع واجهة عربية، لوحات إحصائية، تقارير، ومؤشرات تساعد على اتخاذ القرار.

## ✨ نظرة سريعة

- 🔐 تسجيل دخول وإدارة جلسات المستخدمين
- 📊 لوحة معلومات تفاعلية للمؤشرات الرئيسية
- 🏢 إدارة بيانات المؤسسات (إضافة، تعديل، حذف، استعلام)
- 🌱 حساب مؤشر الأداء الأخضر (Green Score)
- 📈 تقارير ومقارنات بين السنوات والمؤسسات
- 🔔 تنبيهات عند ارتفاع انبعاثات الكربون
- ⚙️ صفحة إعدادات وإشعارات
- 🗄️ دعم SQLite افتراضيا مع إمكانية استخدام PostgreSQL أو MySQL/MariaDB

## 🧱 المتطلبات

- **Windows 64-bit** (7/10/11)
- لا يلزم تثبيت Python — النسخة المحمولة مضمّنة داخل مجلد `python\`

## 🚀 التشغيل (طريقة واحدة — بضغطة واحدة)

**انقر نقراً مزدوجاً على `run.bat`** — هذا كل شيء.

يقوم الملف تلقائياً بـ:
- تحديد Python المدمج في مجلد `python\`
- التحقق من المكتبات وتثبيتها إذا لزم من مجلد `packages\`
- تشغيل التطبيق وفتح المتصفح على `http://localhost:5000`

> ملف `.env` موجود مسبقاً بإعدادات جاهزة للتشغيل — لا حاجة لأي تعديل.

### أول تشغيل

عند التشغيل لأول مرة يُنشأ حساب المدير تلقائياً:

| الحقل | القيمة |
|-------|--------|
| اسم المستخدم | `admin` |
| كلمة المرور | `admin123` |

> **مهم:** غيّر كلمة المرور فور تسجيل الدخول الأول.

### التشغيل عبر Terminal (بديل)

```powershell
python app.py
```

يلزم في هذه الحالة وجود Python 3.10+ وتثبيت المكتبات:</p>

```powershell
pip install -r requirements.txt
```

## 🛠️ أهم متغيرات البيئة

راجع القيم في `.env.example`، وأهمها:

- `SECRET_KEY`: مفتاح تأمين الجلسات (لا تستخدم قيمة افتراضية في الإنتاج)
- `SETUP_SECRET`: مفتاح إنشاء المدير الأول عبر واجهة `/api/init-admin`
- `DATABASE_URL`: رابط PostgreSQL أو MySQL/MariaDB (اختياري)
- `CARBON_ALERT_THRESHOLD`: حد التنبيه لانبعاثات الكربون
- `MAIL_ENABLED`: تفعيل/تعطيل البريد الإلكتروني للتنبيهات

## 🐬 تشغيل على XAMPP (MariaDB)

1) شغّل خدمة MySQL من لوحة تحكم XAMPP.
2) أنشئ قاعدة بيانات باسم `green_economy` (مثلاً عبر phpMyAdmin).
3) أضف في ملف `.env`:

```text
DATABASE_URL=mysql://root:@localhost:3306/green_economy
```

4) ثبّت الاعتمادات:

```powershell
pip install -r requirements.txt
```

5) شغّل التطبيق:

```powershell
python app.py
```

## 📡 أهم واجهات API

- `GET /api/dashboard-stats` إحصاءات لوحة المعلومات
- `GET /api/institutions` جلب سجلات المؤسسات
- `POST /api/institutions` إضافة سجل مؤسسة
- `PUT /api/institutions/<id>` تحديث سجل مؤسسة
- `DELETE /api/institutions/<id>` حذف سجل مؤسسة
- `GET /api/reports` تقارير سنوية ومقارنات
- `GET /api/green-scores` نتائج المؤشر الأخضر

## 🔒 توصيات الأمان قبل النشر

- غيّر جميع القيم السرية الافتراضية في ملف `.env`.
- لا ترفع ملف `.env` إلى Git أو أي مستودع عام.
- شغّل التطبيق خلف خادم إنتاج مناسب (WSGI/Reverse Proxy).
- فعّل نسخا احتياطية دورية لقاعدة البيانات.
